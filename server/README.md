# MailApp Management Server

Лёгкий сервер управления версиями клиента MailApp. PHP + SQLite, без фоновых
служб — работает на обычном web-хостинге (например, с панелью TinyCP).

## Что делает

- Принимает heartbeat от клиентов (имя ПК, локальный IP, версия, профиль).
- Показывает список клиентов в веб-панели (сортировка по имени ПК).
- Управляет кодами подключения (создать / пересоздать / показать / копировать).
- Позволяет точечно поставить команду «обновиться» для каждого клиента.

Обновления раздаются **с этого сервера** (по HTTPS): админ загружает установщик
`MailApp-Setup-X.Y.Z.exe` в разделе «Файл обновления», он сохраняется в папку
`updates/`, а служба клиента качает его с сервера и проверяет по sha256.

Требования к хостингу для загрузки:
- **HTTPS** с сертификатом, которому доверяют клиентские ПК (внутренний CA или
  валидный сертификат) — служба качает по HTTPS и проверяет сертификат.
- `upload_max_filesize` и `post_max_size` в PHP больше размера установщика
  (~90–120 МБ).
- Папка `updates/` должна быть доступна на запись веб-серверу и отдавать `.exe`
  (некоторые хостинги блокируют `.exe` через mod_security — нужно разрешить).

## Установка (первый раз)

1. Распакуйте `MailAppServer.zip` в корень сайта.
2. Скопируйте `config.example.php` → `config.php` и заполните:
   - `server_url` — адрес, по которому клиенты видят сервер (например
     `http://192.168.1.10`).
   - `connect_secret` — длинная случайная строка. **Та же** должна быть зашита
     в клиенте (`CONNECT_SECRET` в `src/main.js`).
   - `admin_password` — пароль для входа в панель.
3. Откройте сайт в браузере, войдите, создайте код подключения.
4. Скопируйте код и вставьте его в клиент (Настройки → Обновление → Сервер
   управления).

Требования: PHP 7.4+ с расширениями `pdo_sqlite` и `openssl`.

## Обновление сервера

Скачайте новый `MailAppServer.zip` из релиза и распакуйте поверх файлов.
`config.php` и `mailapp.db` лежат в корне и **в архив не входят**, поэтому
настройки и данные не затираются.

## Файлы

| Файл | Назначение |
|------|-----------|
| `index.php` | веб-панель (логин + дашборд + действия) |
| `api.php` | endpoint для клиентов (pairing + heartbeat) |
| `db.php` | подключение к SQLite + схема |
| `helpers.php` | конфиг, крипто кода подключения, утилиты |
| `config.example.php` | шаблон конфига (копировать в `config.php`) |
| `mailapp.db` | база (создаётся автоматически, не в архиве) |
