Запуск
Автозапуск при входе в систему
Хранение данных авторизации
Выберите диск — данные сохранятся в {буква}:\MailApp\. Если у вас подключён сетевой диск с одной и той же буквой на всех ПК — данные авторизации будут общими, и приложение войдёт автоматически на любом компьютере.
Автовход
Учётные данные сохраняются по указанному выше пути. Если авторизация слетит — приложение войдёт автоматически.
Обновления
Нажмите «Проверить» для поиска обновлений
Обновления загружаются с GitHub Releases. После скачивания приложение перезапустится автоматически.
