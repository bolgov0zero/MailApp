# MailApp

Electron-приложение для работы с [e.mail.ru](https://e.mail.ru).

## Функции

- Открывает веб-интерфейс e.mail.ru в нативном окне
- Кнопка настроек в правом нижнем углу
- Автозапуск при входе в систему
- Хранение данных авторизации на сетевом диске (глобальные настройки для всех пользователей ПК)
- Автовход при сбросе сессии
- Автообновление через GitHub Releases

## Разработка

```bash
npm install
npm start
```
